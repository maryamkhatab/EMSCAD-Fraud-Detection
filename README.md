# Fraudulent Online Job Posting Detection Using Machine Learning

## Project Overview

This project investigates the detection of fraudulent online job postings using machine learning and the Employment Scam Aegean Dataset (EMSCAD).

## Dataset

The dataset contains legitimate and fraudulent job advertisements with textual and structured attributes.

## Methodology

1. Data preprocessing
2. Duplicate removal
3. Text cleaning and lemmatization
4. TF-IDF feature extraction
5. One-hot encoding
6. Hybrid feature construction
7. SMOTE for class imbalance
8. Model training and evaluation
9. Stacking ensemble
10. SHAP explainability

## Machine Learning Models

- Logistic Regression
- Random Forest
- Linear SVM
- XGBoost
- LightGBM
- Stacking Ensemble

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Average Precision

## Technologies

Python, Jupyter Notebook, Pandas, NumPy, Scikit-learn, NLTK, Imbalanced-learn, XGBoost, LightGBM, SHAP, SciPy, and Matplotlib.
